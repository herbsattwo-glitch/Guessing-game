# Guess the Secret Number 🎯

## Overview
A simple browser-based number guessing game where the player tries to guess a randomly generated secret number between 1 and 20.

## How to Play
1. Open `index.html` in any web browser
2. Type a number between **1 and 20** into the input field
3. Click the **Guess** button
4. Read the feedback message and keep guessing until you get it right

## Feedback Messages
| Message                 | Meaning                                |
|-------------------------|----------------------------------------|
| ✅ Correct Guess!       | You found the secret number            |
| 🟠 Incorrect, too low   | Your guess is below the secret number  |
| 🔴 Incorrect, too high  | Your guess is above the secret number  |

## Project Structure
- `index.html` — Game layout and structure
- `style.css` — Styling and animations
- `script.js` — Game logic
- `README.md` — Project documentation

## Technologies Used
- **HTML** — Page structure and input elements
- **CSS** — Styling, layout, and animated gradient background
- **JavaScript** — Random number generation and guess checking logic

## Features
- Random secret number generated on every page load
- Instant feedback after each guess
- Animated gradient background
- Clean and responsive card layout
- Color-coded feedback messages

## How to Run
1. Download or clone the project files
2. Open `index.html` in your browser
3. Start guessing!
